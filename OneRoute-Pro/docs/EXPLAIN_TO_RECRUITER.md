# Honest project summary

OneRoute Pro is a Chennai transit route-planning prototype using a C++17 graph engine, Java Spring Boot REST API and React frontend. It models boarding and transfer context, supports four routing objectives, and computes up to three station-simple alternatives with Yen's algorithm. The backend includes validation, generated Swagger documentation, a bounded native-worker pool and a constraint-aware LRU cache.

The network data is a curated demonstration dataset, not verified live railway data. The project demonstrates algorithms, API design, testing and interface integration. It does not include MySQL, JWT, live tracking or an official fare engine.
